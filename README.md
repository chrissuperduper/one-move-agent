# One Move agent resources

Public, agent-facing resources for [One Move](https://getonemove.app): the AGENTS.md rules, the Agent Plugins manifest, the MCP configuration and the published skills.

- Website: https://getonemove.app
- API: https://api.getonemove.app/v1
- OpenAPI: https://api.getonemove.app/openapi.json
- MCP product: https://api.getonemove.app/mcp
- MCP docs: https://api.getonemove.app/docs/mcp
- llms.txt: https://getonemove.app/llms.txt
- auth.md: https://getonemove.app/auth.md

The application source lives in a private repository; this repository exists so AI clients and coding agents can discover the public agent contract without access to the source.
